# 🚀 Explorador del Sistema Solar

Un sistema solar interactivo con una nave que puedes pilotar a hipervelocidad,
aterrizar en cada uno de los 8 planetas y descubrir su vida alienígena.

## Cómo ejecutarlo en tu Mac

1. Descarga el archivo `index.html`.
2. Haz doble clic sobre él (se abrirá en Safari o Chrome).

No necesita internet ni instalación: todo está dentro del archivo.

## Controles

| Tecla | Acción |
|---|---|
| ↑ | Acelerar |
| ← / → | Girar la nave (en superficie: explorar) |
| ↓ | Frenar |
| **Shift** | ⚡ Hipervelocidad |
| 1 – 8 | Fijar un planeta como destino (flecha guía) |
| **E** | Aterrizar (cuando estés cerca de un planeta) |
| **Q** | Despegar |
| H | Mostrar / ocultar la ayuda |

## Los habitantes

- **Mercurio** — Ferrolitos, cangrejos de caparazón metálico
- **Venus** — Nubelinas, medusas doradas que flotan sobre las nubes
- **Tierra** — Verdianos, simpáticos alienígenas verdes con antenas
- **Marte** — Marcianos, los clásicos grises de ojos enormes
- **Júpiter** — Globoides, criaturas globo que nunca tocan el suelo
- **Saturno** — Anillados, patinadores de hielo con coronas de anillos
- **Urano** — Cristalinos, seres geométricos de hielo vivo
- **Neptuno** — Abisales, calamares bioluminiscentes
